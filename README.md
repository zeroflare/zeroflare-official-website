# 零曜科技官方網站 Zeroflare

零曜科技的官方網站，採用純前端技術（HTML、CSS、JavaScript）開發。

## 專案結構

```
zeroflare-official-website/
├── index.html          # 首頁
├── about.html          # 關於我們
├── products.html       # 產品服務
├── contact.html        # 聯絡我們
├── styles/
│   └── main.css        # 主要樣式檔案
├── scripts/
│   ├── main.js         # 主要 JavaScript 功能
│   └── contact.js      # 聯絡表單處理
├── LICENSE             # 授權文件
└── README.md           # 說明文件
```

## 功能特色

- ✅ 響應式設計，支援各種裝置
- ✅ 現代化的 UI/UX 設計
- ✅ 流暢的動畫效果
- ✅ 行動裝置選單
- ✅ 聯絡表單功能
- ✅ 純前端實現，無需後端

## 使用方式

### 本地開發

1. 直接在瀏覽器中開啟 `index.html` 檔案
2. 或使用本地伺服器：

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js (需要安裝 http-server)
npx http-server

# 使用 PHP
php -S localhost:8000
```

3. 在瀏覽器中訪問 `http://localhost:8000`

### 部署

將所有檔案上傳到任何靜態網站託管服務，例如：
- GitHub Pages
- Netlify
- Vercel
- 任何支援靜態網站的伺服器
